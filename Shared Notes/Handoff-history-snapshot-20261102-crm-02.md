## Read-only Hardcoded-Behavior Audit (October 3, 2026)

This was a static, read-only audit of the tracked CRM and GoGreenMonthlyDrafts application sources, database migrations, and production call sites. No application code was changed. Findings are classified as keep hardcoded, candidate for an administrator setting, needs review, or obsolete/dormant/map-only.

### Highest-priority findings requiring review

- Runtime activity attribution requires exactly one active associate named `Robert Nevins` (`Data/CRMRepository.vb`, `ResolveDefaultAdministratorAssociateId`, around lines 1522-1527). Until authentication is implemented, tracked activities are always attributed to this hardcoded identity and activity writes fail if it is renamed, inactive, missing, or duplicated. The schema-21 migration's initial `robert.nevins` administrator seed is an approved immutable migration decision; the continuing runtime name lookup is the part needing review.

UPS fulfillments therefore do not start the Labels suppression clock and do not appear as labels sent activity in history.
